# KOSDAQ150 구성종목 스냅샷 검증 (#46)

## 방법

수동 다운로드한 KRX 화면의 날짜별 구성종목 파일 129개(`data/manual/krx_constituents/`)를 읽는다. 파일명 날짜를 KRX Open API 거래일과 대조하고, 파일의 모든 종목코드·종가를 같은 날짜의 Open API 코스닥 일별매매정보와 비교한다. 연속 **거래일**의 스냅샷이 모두 있는 경우에만 종목 집합의 차이로 편입·편출을 확인한다. 따라서 4개 연속 날짜가 있으면 중간 날짜를 공유하는 3번의 변화를 모두 검사한다.

팀이 이전에 크롤링해 정리한 KRX 공지 목록 69행(`data/manual/events/kosdaq150_changes_2015_2025.csv`)은 적용일만 대조한다. 이 CSV는 KRX 공지 원문 자체가 아니고 종목코드도 없으므로 편입·편출 종목과 공지 원문의 일치 여부는 자동으로 확인할 수 없다. 엑셀 원본·공지 목록·검증 상세 CSV는 `data/` 아래에 두고 Git에 올리지 않는다.

```bash
.venv/bin/python -m src.constituent_validation
```

결과는 `data/validation/constituents/`의 `SUMMARY.md`, `manifest.csv`(파일 해시 포함), `transitions.csv`, `price_errors.csv`, `unresolved_notices.csv`에 저장된다. 기존 일별 구성종목 파일을 확보하면 다음 옵션으로 각 스냅샷 날짜의 종목 집합을 추가 대조한다.

```bash
.venv/bin/python -m src.constituent_validation \
  --legacy-snapshots /path/to/raw/aie_history/snapshots_2203.csv
```

기존 실험 산출물 `dev_openapi/event_phases.parquet`가 있으면 `--experiment-events`로 지정한다. `short_shock` 시작일을 적용일로 읽어 종목·방향을 공식 변경과 대조하고, 첫 공식 스냅샷을 시작 집합으로 이벤트를 순차 적용해 이후 공식 스냅샷과 비교한다. 상세 결과는 `experiment_event_comparison.csv`, `experiment_membership_comparison.csv`에 저장한다.

```bash
.venv/bin/python -m src.constituent_validation \
  --experiment-events /path/to/data/dev_openapi/event_phases.parquet
```

## 실험 산출물 대조

사용자가 제공한 기존 `data/dev_openapi/event_phases.parquet`(생성 시각 `2026-10-19`, `as_of=2024-12-30`, `reportable=false`)에는 편입·편출 이벤트 584건이 있다. 공식 전후 스냅샷으로 관측 가능한 62개 변경일의 **584건이 적용일·종목코드·방향 모두 일치**한다.

첫 공식 파일 `2015-07-13`의 종목 150개를 시작 집합으로 실험 이벤트를 적용하면, 실험 기간에 속하는 공식 파일 **123개 모두**와 구성종목 집합이 일치한다. 첫 파일은 시작 집합으로 사용했으므로 독립 대조는 이후 122개 파일이다. `2015-07-13`과 `2015-12-10`의 종목 목록도 동일하다. 이 결과는 관측한 날짜에서 기존 실험 이벤트가 공식 목록을 재현한다는 뜻이다. 스냅샷 사이의 매일을 검증했다는 뜻은 아니다.

## 아직 필요한 검증

기존 일별 구성종목 이력 파일 `snapshots_2203.csv`가 제공된 폴더에 없어 **기존 이력의 각 날짜를 직접 읽어 비교하지는 못했다.** 실험 산출물의 이벤트를 통한 재구성과는 다른 검사다. 파일을 확보하면 위 옵션으로 직접 대조할 수 있다. 공지에 종목코드가 없으므로 위 8건의 공지 원문·후속 공지와 적용일도 직접 대조해야 한다.

스냅샷 사이의 모든 거래일을 받은 것은 아니므로 그 사이의 다른 변경을 배제할 수 없다. `2015-07-13` 시작 목록을 확인했지만 `2015-07-14`부터 `2015-12-09`까지 매일 확인한 것은 아니다. 현재 실험 기준일은 `2024-12-30`이고, 2025년 스냅샷 6개는 향후 기간 검증에만 해당한다. 이 제약을 해소하고 기존 일별 이력을 직접 대조하기 전까지 전체 거래일의 구성종목 이력을 공식 자료로 확정하지 않는다.
