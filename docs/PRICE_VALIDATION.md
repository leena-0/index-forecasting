# KRX 기준가 수익률과 수정주가 수익률 비교

이 문서는 이슈 #34의 외부 검증 절차를 설명한다. KRX Open API 기준가 방식(#30)과 기존 네이버 수정 OHLC의
**수익률**을 비교한다. 네이버 데이터는 최종 모델 입력이나 공식 결과의 근거로 사용하지 않는다.

## 비교 정의

| 항목 | KRX Open API | 기존 네이버 수정 OHLC |
|---|---|---|
| 종가 수익률 | `ln(close / base_price)` | `ln(adjusted_close / adjusted_close.shift(1))` |
| 야간 수익률 | `ln(open / base_price)` | `ln(adjusted_open / adjusted_close.shift(1))` |

`base_price = close - CMPPREVDD_PRC`이며 `FLUC_RT` 내부 검증을 통과한 행만 사용한다. 가격 수준은 수정 기준일에
따라 다를 수 있으므로 직접 비교하지 않는다.

일반 거래일과 기준가 조정일을 나눠 집계한다. 기준가 조정일은 KRX `base_price`가 수정 전 전일 종가와 다른 날이다.
기존 1.3/0.7·주식 수 1.5배 `corp_action` 플래그도 `comparison.csv`에 함께 남겨 대조할 수 있다.

## 실행

기존 데이터 폴더에서 다음 두 수정 OHLC 폴더를 지정한다. 하나만 존재하면 하나만 지정해도 된다.

```bash
python -m src.price_validation \
  --adjusted-dir /path/to/kosdaq150_forecast/data/raw/aie_history/stocks \
                 /path/to/kosdaq150_forecast/data/raw/stocks \
  --start 2015-07-13 \
  --end 2024-12-30
```

특정 종목만 먼저 확인하려면 `--ticker 035720`처럼 반복해서 지정한다. 기본 허용 오차는 로그수익률 `1e-4`
(약 1bp)이며 `--tolerance`로 바꿀 수 있다.

기존 네이버 파일을 새로 수집하지 않는다. 이미 보유한 개발용 데이터를 읽기만 하며 원본은 수정하지 않는다.

## 개발용 검증 결과 (2026-11-05)

2015-07-13~2024-12-30의 KRX 기준가 조정 종목을 연도별 최대 3개씩 뽑아 27종목을 선정했다. 기존 네이버
수정 OHLC와 공통으로 수익률을 계산할 수 있는 54,220행(일반일 54,120행, 기준가 조정일 100행)을 비교했다.
개발용 외부 검증이며 결과 보고용 수치가 아니다.

절대오차는 로그수익률에 10,000을 곱한 bp 단위로 표시했다.

| 구분 | 수익률 | 평균 절대오차 | 중앙값 절대오차 | 최대 절대오차 | 1bp 초과 |
|---|---|---:|---:|---:|---:|
| 일반일 | 종가 | 0.988bp | 0.193bp | 29.725bp | 두 수익률 중 하나라도 초과한 행 41.7% |
| 일반일 | 야간 | 1.372bp | 0.300bp | 32.600bp | 위와 같음 |
| 기준가 조정일 | 종가 | 0.947bp | 0.179bp | 11.447bp | 두 수익률 중 하나라도 초과한 행 41.0% |
| 기준가 조정일 | 야간 | 1.155bp | 0.422bp | 14.368bp | 위와 같음 |

기준가 조정일의 평균·최대 오차와 1bp 초과 비율이 일반일보다 크지 않았다. 따라서 기업행사일에
`base_price = close - CMPPREVDD_PRC`를 사용한 방식이 추가적인 가짜 가격 점프를 만들었다는 증거는 없으며,
네이버 수정주가 수익률과 실질적으로 유사하게 동작한다고 판단한다.

1bp 허용치를 넘은 행은 22,609개지만 이를 곧바로 불일치로 해석하지 않는다. 네이버 수정 OHLC가 정수 가격으로
반올림되므로 저가 종목의 두 가격 비율에는 1bp 안팎의 차이가 쉽게 생긴다. 실제로 정수 가격의 ±0.5원 반올림만으로
설명 가능한 범위에 종가 수익률 오차의 81.5%, 야간 수익률 오차의 67.4%가 들어갔다. 5bp를 넘은 비율은
기준가 조정일 5.0%, 일반일 10.2%였고, 20bp를 넘은 기준가 조정일은 없었다.

가장 큰 기준가 조정일 사례는 123010의 2022-06-16이었다. KRX 원가격은 기준가 770원, 시가 765원,
종가 786원이었고 네이버 수정가격은 전일 종가 5,923원, 시가 5,893원, 종가 6,053원이었다. 두 가격 체계의
비율 방향은 같지만 수정계수와 정수 가격 반올림이 완전히 일치하지 않아 종가 11.45bp, 야간 14.37bp 차이가 났다.
이는 가짜 분할 수익률이 남은 경우가 아니라 외부 제공자의 수정계수·반올림 차이로 분류한다.

남은 큰 오차 사례는 다음을 구분해 검토한다.

- 반올림 및 호가 단위 차이
- 수정 기준일 또는 기업행사 반영 범위 차이
- 거래정지·신규상장 등 한쪽에서만 수익률을 계산할 수 없는 행
- 실제 기준가 처리 불일치

자동 테스트는 일반일과 2:1 분할 예제에서 두 방식의 종가·야간 수익률이 일치하는지 확인한다.
