## 2. 확인된 사실

### 2.1 KRX Data Marketplace 이용약관과 IP 차단 (2026-10-17)

- 본 수집(작업자 3개, 초당 약 2.5건) 시작 약 1분 30초 뒤 IP가 **1일 차단**됨.
- 차단 안내: "자동화 수단을 통한 비정상 대량 조회 감지". **이용약관 제10조 제2호**가 자동화 수단을 이용한
  정보 무단 수집·복제·배포를 금지하고, 제6조 제2항에 따라 위반 시 이용이 제한될 수 있음. 해제 후에도 자동 수집은 제한되며
  화면 다운로드, 데이터 상품 구입, KRX Open API 등 **공식 경로**를 쓰라고 안내함.
- 문제는 속도가 아니라 **방식**(화면용 내부 주소를 스크립트로 호출). 순차 1초 간격 시험 수집, pykrx 기반 수집
  (팀원 `setup/common-pipeline`, 이전 개인 프로젝트)도 같은 범주. 병렬 수집은 탐지를 앞당겼을 뿐.
- 약관 원문 전체는 아직 못 읽음 — "무단"의 범위, 학술·연구 예외 여부 확인 필요 (3.1).

### 2.2 KRX Open API (openapi.krx.co.kr, 공개 문서·라이브러리 코드 기준)

- 자동 호출이 허용되는 공식 경로. 인증키 + API별 이용신청·승인, **키당 하루 10,000건**, 2010년~, 매일 08시 갱신.
- 비상업적 이용, 제3자 제공 금지, "한국거래소 통계정보" 출처 표시 (2차 자료 기준, 원문 확인 필요).
- **제공**: 코스닥 일별매매정보(날짜별 전 종목 시가·고가·저가·종가·거래량·거래대금·시가총액·상장주식수, **수정 안 된 가격**),
  코스닥 지수 일별시세, 종목기본정보(상장일). 2015~2025년은 약 2,700회 호출.
- **제공 안 함**: 수정주가, 공매도, 지수 구성종목 이력, 지수 내 비중.

### 2.3 KRX 응답에서 확인한 것 (크롤러 시험 수집)

- 요청 1건의 기간은 2년 이하 (넘으면 400).
- 구성종목 응답에 **지수 내 비중 열이 없음**. `MKTCAP`은 상장시가총액이라 유동비율·비중 상한이 반영된 실제 지수 비중과 다를 수 있음.
- 수정주가는 OHLC만 수정되고 거래량·거래대금·시가총액은 원래 값. 같은 계정의 동시 로그인은 서로를 끊지 않음.

### 2.4 기존 개인 수집 데이터 (`kosdaq150_forecast/data`)

| 항목 (CLAUDE.md 2.2) | 상태 |
|---|---|
| 기간 | 2015-07-13 ~ 2024-12-30 — **2025년 없음** |
| 수정 OHLC | 있음, **네이버 출처** (KRX와 약간 다름: 카카오 2015-07-13 종가 네이버 27,056 / KRX 27,163) |
| 거래량 · 시가총액 · 상장주식수 | 있음 |
| 종목별 거래대금 · 공매도 · 상장일 · 지수 비중 · 공지일 | **없음** |
| 구성종목 이력 | 거래일별, 386종목 (편출·상장폐지 포함), 구성종목 변화와 이벤트 584건이 모두 일치 |

### 2.5 파이프라인 1단계를 기존 데이터로 실행한 결과 (개발용 건수, 결과 아님)

- 이벤트(공지일 기준): train 462 / val 64 / test 58 → **경계를 넘어 제외: train 28 / val 64(전부) / test 38**
